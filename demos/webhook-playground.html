Webhook to Discord

A webhook is a message one system sends to another when something happens. Here, a self-hosted Gitea server sends events, and a small Spring Boot service I wrote turns them into Discord messages. This playground re-creates its main rules in your browser.

Demo only. This is a simplified JavaScript re-creation of my giteaNotificator service. Nothing is sent to a real Discord server. The channels, names and message format here are simplified for the demo.

1. Build a webhook

Try it: press Send twice quickly. The same delivery ID arrives two times within 5 seconds, and the second one is ignored.

Rules in this demo

  1. An empty body returns 400.
  2. The same delivery ID within 5 seconds is ignored.
  3. A repository called giteaFinalProject posts to #team-updates.
  4. Events by user moslem post to #my-events.
  5. Anything else is accepted but not posted.
